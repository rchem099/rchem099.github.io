01 · COMPUTER ARCHITECTURE

5-Stage RISC Pipeline Processor

I built a five-stage MIPS-style processor in VHDL with fetch, decode, execute, memory and write-back stages. The design used an 8-bit datapath, 32-bit instructions and separate instruction and data memories. I integrated pipeline registers, hazard detection and forwarding to handle instruction dependencies and control hazards.

Single-Cycle MIPS Processor

03 · HARDWARE ARITHMETIC

16-Bit Floating-Point Arithmetic Unit

I designed floating-point addition and multiplication circuits in structural VHDL using a custom 16-bit format with a sign bit, a 7-bit exponent biased by 63 and an 8-bit mantissa. The design combined sign and exponent logic, mantissa arithmetic, normalization and overflow detection in synchronous, resettable datapaths.

04 · DIGITAL CONTROL

FPGA LED Pattern Controller

I designed a controller for an eight-LED display using the Algorithmic State Machine methodology and structural VHDL. Separate left and right controls selected moving light patterns, with combined motion when both were active and preserved positions when paused. I separated the datapath from one-hot control logic and included a global reset and clock division.

Signed Fixed-Point Arithmetic Unit

I designed a fixed-point ALU in structural VHDL for signed 4-bit addition, subtraction and multiplication, with an 8-bit product. I used ASM diagrams to define the multiplier datapath and control logic, integrated operation selection, and exposed carry, zero and overflow status signals.

06 · DIGITAL CONTROL

Sensor-Driven Traffic Light Controller

I designed a synchronous finite-state machine in VHDL to coordinate traffic lights at a main-road and side-road intersection. The controller prioritized the main road, responded to a side-road vehicle sensor, and used programmable green intervals with timed yellow transitions. I combined state logic, counters and comparators with clock division and input debouncing.
